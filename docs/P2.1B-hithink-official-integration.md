# P2.1B Hithink Official Market Data Integration

本轮为独立 REST Provider 和验收入口，不改变 Production 默认入口、auto 优先级或消费者。保留 Tencent/Sina、XtDataCenter/QMT 和此前未提交的 AKShare/BaoStock 日K实现；不实现分钟价格K线、板块热度或交易逻辑。

## 契约与配置

接口依据仅为本轮指定的官方 llms-full.txt。桌面副本名为“llms-full.txt .txt”，存在URL斜杠/JSON标点缺失；从用户文档索引明确列出的 https://fuyao.aicubes.cn/llms-full.txt 获取可解析原文核对。两份聚合文档存放在任务work目录，不加入仓库。SHA及长度见任务输出中的contract_provenance.json。

只读取 FUYAO_API_KEY；FUYAO_BASE_URL 默认 https://fuyao.aicubes.cn。不改真实.env，不迁移或读取其他命名的凭据。初始化不要求Key、不联网；实际请求缺Key返回AUTH_NOT_CONFIGURED。snapshot批次通过capability_status/errors暴露错误；quote保持MarketSnapshot返回形状，详细错误见realtime.last_batch及client.events。历史错误保存在warnings，绝不静默跨源fallback。

.env.example提供空Key和base URL。模式工厂新增hithink；free仍为腾讯主源/新浪备用，auto/xtdc/qmt原语义不变。原Production入口本轮没有改接工厂，设置Key不会自动切源。

## REST能力

| 能力 | 契约路径 | 本轮实现 |
|---|---|---|
| 股票名单 | /api/meta/tickers/list | asset_type=a-share，limit=1000，offset递增，短页终止 |
| 代码验证 | /api/meta/tickers/search | 官方目录核对标准指数 |
| 股票快照 | /api/a-share/prices/snapshot | quote/snapshot/snapshot_all；全市场limit=100，不猜最大值 |
| 股票日K | /api/a-share/prices/historical | 单标的，interval=1d，start/end毫秒 |

| 指数快照 | /api/a-share-index/prices/snapshot | 必须显式thscodes；无全指数分页 |

## 错误与限流

同时检查HTTP和ApiResponse.code。HTTP200且code0且data.item符合信封结构才SUCCESS。映射：

- 1001/1002/1003/1004：REQUEST_ERROR
- 2001：AUTH_INVALID；2003：PERMISSION_DENIED
- 3001：SYMBOL_NOT_FOUND；3002：DATA_NOT_READY；3004：UNSUPPORTED
- HTTP429或4001：RATE_LIMITED
- 5001：SERVER_ERROR；5002：UPSTREAM_TIMEOUT；5003：UPSTREAM_UNAVAILABLE
- 非200其他HTTP：HTTP_ERROR；格式异常：PROTOCOL_ERROR；传输异常：NETWORK_ERROR

权限失败不会污染其他能力。全流程串行，没有高并发。429/4001及可重试上游异常登记2/4/8…最高60秒退避，尊重Retry-After并设600秒等待上限；冷却期不发HTTP。不在当前调用内立即重试。触发限流/冷却停止当前分页，保留成功页并标PARTIAL；普通可隔离页错误在已知total时继续后续页。初页失败无法确定total时停止，不能猜页数。

诊断仅记录能力、HTTP status、code、脱敏message/request_id、耗时、条数、时间戳、retry_after。凭据字段从序列化数据剔除；完整Key及固定前后片段脱敏，异常只记录类型。禁止跟随HTTP重定向携带凭据到其他地址。HTTP超时15秒、响应体16MB安全上限。

## Schema和单位

MarketSnapshot继续统一六位.SH/.SZ/.BJ；模型额外允许官方.TI指数代码，旧A股adapter的入参校验仍不接受.TI。映射：
thscode→symbol，last_price→price，prev_price→prev_close，
open/high/low_price→open/high/low，price_change→change，
price_change_ratio_pct→pct_change，volume→volume_shares，
turnover→amount_cny，data.timestamp→带Asia/Shanghai时区的quote_time。
官方量为股、额为人民币元，不乘100/10000。

name仅从官方ticker缓存补充；不重复按每条快照查name。turnover_rate、volume_ratio、total_market_cap、float_market_cap保留null。不混入腾讯旧字段。真实零价变不可用price=null；真实零量不冒充缺失值。

HistoricalBar复用此前日K公共结构。date_ms按Asia/Shanghai映射trade_date；OHLC_price、volume、turnover直接映射；prev_close/pct_change没有源字段则null。价格默认raw→none，与现有QMT/XTDC的dividend_type=none一致；qfq→forward、hfq→backward。指数仅raw且不发送adjust。不允许1m/5m/30m；请求窗口保守限制3650日，确保不超过官方10年。

## Freshness与时间含义

复用P2.1A推进状态机并注入官方日历adapter。交易时首个有效近期样本只建立CACHED基线，后续推进且15秒内才LIVE；停滞、回退或超时STALE；缺时间戳/无有效价UNAVAILABLE。休市最新有效数据标CACHED，允许官方data.timestamp在休市当天更新，不会因HTTP200标LIVE。

官方timestamp是**一页中最新上游时间**，不是每只证券独立成交时间。批次显式记录timestamp_scope=page_latest_upstream_not_per_symbol。即便页时间推进，也不能据此证明每只停牌/陈旧证券都在成交。正式提升为盘中Primary前必须单独验证这一限制；当前休市smoke不构成盘中LIVE验收。

## 名单、日历、目录缓存

默认data/hithink/reference下按日缓存；临时文件+fsync+原子replace。名单保留symbol/ticker/name/exchange/asset_type/currency/list_date，并映射Security的board；交易所必须与官方后缀一致，不猜裸代码。分页失败不会把半份名单缓存成完整主表。腾讯bootstrap完整保留，仅作为未来有明确诊断的fallback设计，本轮hithink不自动调用。

日历adapter提供现有is_trading_day接口，market_session无需重写。官方一年窗口内使用官方交易日集合；窗口外或能力不可用时保留现有日历判断，并可通过last_result/start/end检查来源覆盖范围。尚不修改free模式的现有时钟。

THS目录缓存index_thscode/index_name/tag/updated_at；按需缓存members，同日复用。不自动抓取全部概念成分，不扩展财务/资金流/热度算法。

## 历史增量与缓存

复用FreeHistoryCache，键含symbol/source=hithink/endpoint=official_rest/kind/adjustment，与其他源隔离。保存last_trade_date/updated_at。缓存足够且最新日期达到目标日时零历史网络请求；否则从最后日期开始含一个重叠bar请求start/end，合并校验后写回。官方REST支持日期区间，不存在此前AKShare新浪SDK必取全历史的问题。

qfq/hfq重叠OHLC发生变化或没有重叠时，重新请求保留窗口，禁止直接拼接不同复权基准。重建失败保留可诊断缓存，不伪装为新数据。失败有进程内300秒再次抓取冷却，不会每次页面刷新重试。

以官方日历计算最近完成交易日，沿用保守18:00发布缓冲；盘中排除当日日K。校验OHLC、非负量额、日期、重复、未来及缺日。停牌或源缺日没有额外元数据证明时保守PARTIAL。CACHED不代表刚从网络获得；陈旧缓存同时标质量DEGRADED。

## 使用与边界

```powershell
$env:A_AGENT_MARKET_DATA_MODE='hithink'
python scripts/hithink_market_smoke.py --network
python scripts/hithink_market_smoke.py --network --full --cache data/hithink
```

验收脚本从项目.env读取配置（不覆盖进程环境变量），结果落盘；库本身只读取环境或显式client注入。最小probe先验证权限，full模式再做官方全名单、全A快照、6股样本、120日日K、3指数、目录和成分、腾讯交叉对比。

未来候选回退链：Realtime Hithink→Tencent→Sina；History Hithink→AKShare→BaoStock；Universe Hithink→free缓存。仅设计，不上线自动fallback。

本轮工程验收与当前Key权限验收，不能替代盘中长期性能、时戳逐标的语义、限流恢复和数据许可/持续可用性验证。是否提升Primary须人工验收后决定。
