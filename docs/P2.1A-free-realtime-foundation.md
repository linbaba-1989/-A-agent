# P2.1A Free Realtime Market Foundation

本轮只新增免费实时基础层与最小验收入口。现有 app、MarketDataRouter、XtDataCenter、QMT 及消费者代码未修改。未接 Production、未改交易接口、未迁移数据库、未 commit/push。

## 使用与边界

`A_AGENT_MARKET_DATA_MODE` 支持 auto（缺省）、free、xtdc、qmt。通过新工厂 `src.market_data.factory.create_market_provider()` 生效。free 分支仅构建标准库实现的免费 Provider，不导入或初始化付费/QMT 运行时；初始化不请求网络。其他模式委托原 MarketDataRouter，xtdc 映射为其 xtdatacenter 名称。

原 Production 入口本轮没有改接新工厂，因此仅设置 free **不会把现有完整应用切换到免费行情**。这是 P2.1B 的后续接入范围，不代表全应用已完成无付费运行验收。

最小验收（PowerShell，在仓库根目录）：

```powershell
$env:A_AGENT_MARKET_DATA_MODE='free'
python scripts/free_market_smoke.py
python scripts/free_market_smoke.py --network --full
```

上层未来只调用 FreeMarketDataProvider.quote("600498.SH")、snapshot(symbols)、snapshot()、get_stock_universe()。snapshot 返回 SnapshotBatch，包含每个请求标的的快照及覆盖率、有效价、零价、缺失、耗时、错误和时间戳推进指标。未返回标的有明确缓存或 UNAVAILABLE 占位，不会静默消失。当前不提供旧消费者 get_full_ticks 兼容层。

## 统一 Snapshot Schema 与单位

| 字段 | 类型/含义 | 腾讯 | 新浪 |
|---|---|---|---|
| symbol | 六位代码.SH/.SZ/.BJ | 规范化 | 规范化 |
| name | string/null | 直接 | 直接 |
| price | number/null，人民币元 | 直接 | 直接 |
| prev_close | number/null，人民币元 | 直接 | 直接 |
| open / high / low | number/null，人民币元 | 直接 | 直接 |
| change | number/null，人民币元涨跌额 | 直接 | price-prev_close |
| pct_change | number/null，百分数，3 表示 3% | 直接 | change/prev_close*100，昨收非正则 null |
| volume_shares | number/null，当日累计股数 | 手 × 100 | 已是股 |
| amount_cny | number/null，当日累计人民币元 | 万元 × 10000 | 已是人民币元 |
| turnover_rate | number/null，百分数 | 直接 | null |
| volume_ratio | number/null，倍数 | 直接 | null |
| total_market_cap | number/null，人民币元 | 亿元 × 100000000 | null |
| float_market_cap | number/null，人民币元 | 亿元 × 100000000 | null |
| quote_time | 带时区 datetime/null，序列化 ISO 8601 | 源时间 | 源日期+时间 |
| source | string | tencent | sina |
| quote_status | LIVE/STALE/CACHED/UNAVAILABLE | 本地判定 | 本地判定 |

任何源缺失或不可解析字段均为 null；不填 0。真实零成交量可以保留 0。原始零价进入 zero_price_symbols，公开 price/change/pct_change 转 null，状态 UNAVAILABLE。Schema 拒绝 NaN/Infinity、数字字符串和无时区时间。新浪不会用过期腾讯市值拼成“新浪当前真实值”。

内部只接受 600498.SH、000001.SZ、六位代码.BJ；不猜裸代码交易所。sh600498/sz000001/bj代码的转换只在 adapter 内。000001.SH 与 000001.SZ 不混淆。

## 名单

原 get_stock_universe 位于 xtdc_provider.py/qmt_provider.py，免费路径不能靠初始化这些 Provider 获取名单。本轮保留该上层方法形式，并新增免费 bootstrap：腾讯 P2.0 动态全 A 排名名单分页，保存 symbol/name/exchange/board。board 为 MAIN/STAR/CHINEXT/BSE，暂不补股本和行业。

名单内存与磁盘复用，默认 data/free_market/universe.json；每天最多一次刷新尝试，原子写入。失败允许使用最多 7 个自然日的已有名单，超过期限或冷启动无名单则明确报错。不会每 4 秒抓名单。分页唯一代码覆盖要求至少达到接口 total 的 98%；全 A smoke 的覆盖率分母是本轮免费动态名单，不是独立交易所主表认证。冷启动若腾讯名单端点失效，新浪报价仍能用于显式证券列表，但无缓存的全 A bootstrap 暂不能独立恢复。

## Health 与 fallback

每源独立维护 HEALTHY/DEGRADED/UNAVAILABLE、连续成功/失败、coverage_ratio、valid_price_ratio、latency、timestamp_advanced。初始 DEGRADED/warming_up。

合格样本要求：有有效价；覆盖率 ≥95%；有效价率 ≥95%；本轮返回证券中 LIVE 或 CACHED 比例 ≥95%；耗时 ≤15 秒；交易时不能明确检测到时间戳全部停滞。有效价率=正价格数量/实际解析返回数量，覆盖率=实际解析返回数量/请求数量。

连续 2 次不合格降 DEGRADED，3 次 UNAVAILABLE；连续 3 次合格恢复 HEALTHY。一次失败不切源。主源连续 3 次失败后尝试新浪，仅当新浪当前样本合格才切换。切换冷却 30 秒；新浪工作时按调用时机每至少 30 秒探测腾讯，腾讯连续 3 个合格探测并满足冷却后恢复主源。无后台探测线程。两个源都失败时保留明确状态，不把坏 fallback 提升为可用源。

请求最多并发 2 个，腾讯每批 60，新浪每批 800；单次 HTTP 超时 12 秒；30 秒 snapshot 预算在批次间检查，已经开始的请求仍可能增加等待时间，因此不是硬总超时。403/429 后停止安排新批次。坏行、坏批次隔离，不会因个别零价判整源失败。

## Freshness

复用项目现有北京时间交易日历和时段规则。按源、证券、交易日、时段分别跟踪时间戳，并每日清理推进基线。

- 交易时首个足够新的有效时间戳建立基线，保守标 CACHED；后续推进且不超过 15 秒标 LIVE。
- HTTP 成功但同时间戳、倒退时间戳或超过 15 秒标 STALE。
- 午休、收盘及休市的最近有效交易日数据标 CACHED；旧交易日数据标 STALE。
- 无有效价、无时间戳、未来超过 2 秒的时间戳标 UNAVAILABLE。
- 请求失败但有有效缓存，交易时标 STALE；没有缓存则 null/UNAVAILABLE。
- 下午重建推进基线。LIVE 必须有观察到的源时间推进，HTTP 200 本身不构成 LIVE。

休市 CACHED 判定到最近交易日日期级，不证明数据一定来自收盘最后一笔；单次休市 smoke 也不能验证盘中时间推进、午休切换、开盘覆盖或长期限流稳定性。离线用例验证状态机规则；盘中实源验收留待 P2.1B。

## 验收范围

离线 fixture 覆盖解析、symbol、成交量/成交额/市值单位、null、零价、坏行隔离、Health 降级及恢复滞后、四种 freshness、源切换防抖、名单分页及持久缓存/过期、HTTP 编码/限流隔离、无 Token 初始化和旧路由默认行为。公开接口仅做少量单股及全 A smoke，无重试风暴。

本轮不实现 AKShare/BaoStock History、分钟 Bar Builder、技术指标、完整尾盘 selector、板块热度或自动交易。可进入 P2.1B 的消费者契约适配与交易时段影子验收；不可据此宣称免费源已替换 Production 或盘中 LIVE 验收通过。
