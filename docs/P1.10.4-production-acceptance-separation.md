# P1.10.4 Production / Acceptance Separation

Normal mode is available in every market session. Acceptance preflight no longer
stops app rendering, authorizes Beta access, or closes the shared production stream.

Acceptance defaults to OFF. Enable it with `A_AGENT_ACCEPTANCE_MODE=1` or
Settings → System → Developer tools → Acceptance mode. An explicit UI choice
overrides the environment default. Legacy `A_AGENT_ACCEPTANCE_SOURCE` and
`A_AGENT_STREAM_DIAGNOSTICS` no longer enable source locking or acceptance mode.
Allocation diagnostics remain separately controlled by the latter variable.

Normal source choices are Auto, XtDataCenter Token, and QMT Local. Acceptance
temporarily requires Token; leaving it restores the saved normal preference.
Preflight details and counters appear only inside developer acceptance UI.
After close, only Start Acceptance is disabled, with a friendly explanation.

The app uses the existing closed-session snapshot hydration path. Valid quotes
remain CACHED; unavailable speeds remain `--`. Cached Beta frames do not flash
or animate rank movement. Scanner shows its after-hours data basis. AI facts
carry the current market session and actual source without changing prompts.
