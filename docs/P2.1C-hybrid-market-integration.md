# P2.1C Hybrid Market Data Integration

Explicit `A_AGENT_MARKET_DATA_MODE=hybrid` connects the real app, scanner, research and realtime feed to a composite provider. `auto` retains its Production XTDC/QMT selection. `free` and `hithink` remain independent foundation factory options; existing paid modes remain available.

## Routes and identity

|Capability|Primary|Fallback|
|---|---|---|
|Stock realtime|Tencent|Sina, existing health hysteresis|
|Stock daily history|Hithink|AKShare, then BaoStock|
|Security universe|Hithink|Existing free universe cache/bootstrap|
|Calendar|Hithink rolling calendar|Existing calendar outside coverage or on failure|
|Index quote/history|Hithink|Explicit unavailable/degraded|
|Industry/concept catalogs and constituents|Hithink|Dated cache; partial coverage is explicit|

No official full-market realtime request is made by the hybrid all-A loop. Each MarketSnapshot keeps one realtime source and its own quote time; no old official volume is combined with a Tencent price. Enhanced Tencent fields keep Tencent provenance; Sina missing fields stay null.

The consumer compatibility facade supplies existing tick/history methods while preserving shares/CNY units. Shared turnover handling recognizes normalized shares, and research labels display 股 rather than the old QMT 手 label. Field provenance distinguishes realtime, history and reference; derived realtime MA and daily-volume comparisons identify both source dependencies. `volume_ratio` in existing scanner/research factors remains the cumulative daily-volume / historical average-volume factor, not the native vendor volume-ratio definition. The native value stays available on the snapshot/tick.

## Failure policy

History fallback is allowed only after AUTH_NOT_CONFIGURED, AUTH_INVALID, PERMISSION_DENIED, RATE_LIMITED or UPSTREAM_UNAVAILABLE. Other official errors remain visible and do not silently select a different history source. Sequences replace each other with source/adjustment/quality metadata; they are never joined across vendors. Cooldown preserves the reason that permitted fallback. No key does not prevent provider construction or Tencent/Sina quotes.

Optional fallback SDKs are listed in `requirements-free-history.txt`; adapters import SDKs only inside a bounded worker process. Missing SDKs produce unavailable results, not app initialization failures. BaoStock cannot cover Beijing equities. The retained AKShare Sina SDK may internally download more history than the requested window; its isolated timeout and caching remain, and it is only a fallback here.

History, index and reference work do not share the realtime request lock. Index rendering on the realtime page reads cache and schedules a background request. Scanner initialization reads local daily caches; a scan queues at most 30 missing histories, prioritized by amount, with one serial worker and a bounded queue. The next scan adopts completed histories. Until warm, corresponding MA/daily-volume factors remain unavailable. This avoids a synchronous 5,578-symbol official-history bootstrap before first quotes.

## Consumer scope

- Scanner: price, percent change, sampled 1/3/5-minute speed, realtime MA5 and existing daily-volume factors. Speed remains snapshot sampling; no one-minute OHLCV is built or fetched.
- Research: current Tencent/Sina quote, official daily history/reference, source and field provenance in the shared Fact Bundle. DatetimeIndex histories and JSON-compatible dates are supported.
- Dashboard/realtime: three real indices with price, percentage, timestamp and quote status. Source state displays realtime/history/universe/index separately.
- Research industry/concept panel: read cached memberships; explicitly query an official THS index's constituents or start background catalog/member synchronization. It reports covered/total and PARTIAL until all catalogs have cached memberships. An empty partial result does not mean a stock belongs to no sector. No heat score is calculated.

All-A initial and later latency is measured, not promised to equal the UI's requested two-second refresh interval. Existing no-overlap polling remains. Closed/pre-open startup can fetch one real snapshot and displays CACHED, not LIVE. Intraday LIVE still requires advancing source time.

## Verification and operation

```powershell
$env:A_AGENT_MARKET_DATA_MODE='hybrid'
python scripts/hybrid_market_smoke.py --network --output <local-output-path>
python -m streamlit run app.py --server.port=8507
python -m pytest -q
python -m compileall .
git diff --check
```

Do not commit `.env`, keys, local caches, diagnostic outputs or smoke JSON. P2.1C imports the previously untracked free history provider, adapters/history.py, history_parsers.py and history_worker.py; these must accompany a future approved P2.1C commit, plus their optional requirements and tests. P2.1B already committed the shared historical.py/history_cache.py files.

No Production auto promotion, trading API, MinuteBarBuilder, external minute K, 30-minute MACD, KDJ, RSI, final sector heat algorithm or complete late-session selector was introduced. Acceptance here covers engineering and closed/pre-open operation; intraday shadow acceptance remains a separate next stage.
