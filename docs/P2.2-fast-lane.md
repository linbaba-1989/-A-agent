# Realtime Fast Lane

Hybrid/free streaming views own one `FastQuoteService` alongside the existing
full-market feed. Auto/XTDC/QMT selection is unchanged. The small-symbol service
has independent adapters, locks, freshness state, cache and request-health state.
It uses the existing Tencent/Sina parsers, `MarketSnapshot`, `Health` thresholds,
and `FreeMarketDataProvider` fallback/recovery rules.

For a small selected watchlist, no-trade timestamps are not market-wide health
evidence. `RequestHealth` delegates transport/coverage/price/latency evaluation to
the unchanged `Health` implementation using a health-only projection. The actual
quotes keep their original `Freshness` results. This projection is never a public
quote and never reaches Full Market health or cache.

## Subscriptions and bounds

`subscribe(owner, current_symbol, watchlist_symbols)` replaces one viewer's
subscription. `unsubscribe(owner)` releases it. Current symbols precede the union
of watchlists. The global set is limited to 50 symbols; rejected symbols are
reported as `DEGRADED_LIMIT`. The SSE connection owns the subscription and releases
it on disconnect. Streamlit reruns reuse the same streaming resource; only one
fast polling worker runs. With no subscribers it performs no requests.

Both current and watchlist requests are coalesced into one batch with a target
start-to-start interval of one second. No overlapping or catch-up polling occurs.
Each public HTTP request has a three-second timeout. Failures back off up to
30 seconds. Existing three-failure fallback and recovery probe/cooldown behavior
is reused locally; no Full Market source is changed. Outside trading sessions,
polling backs off to at least 15 seconds and quotes use real freshness semantics.

## Separate channels

`events` carries `channel=full_market` and drives Top20/full status. `fast_events`
carries `channel=fast`, per-symbol source/time/date/status, request time and
received time. Independent buses and browser handlers prevent slow full snapshots
from overwriting the fast hero. `fast_only` watchlist views do not subscribe to
the full-market bus. The local capability URL is not an API key and is not logged.

Hybrid's realtime page defaults to dynamic Beta; the normal table remains
available. The current-symbol input and existing Streamlit watchlist feed the
subscription. This is sampled public quote data, not exchange tick/Level-2 data;
a one-second request does not imply a price change every second.

## Short periods

The fast lane reuses `RealtimeSnapshotBuffer` with ten-minute retention. Same
quote timestamps are deduplicated. Existing `speed(1/3/5)` definitions are
unchanged and show unavailable until enough actual session history exists.
Top20 retains its own full-market buffer, isolated from the small-symbol lane.
Bounded samples retain timestamp, price, cumulative volume and cumulative amount
as inputs for future work. No bar builder or volume-delta calculation is added.
Restart starts with an empty ring; no synthetic historical minutes are created.

## Verification boundaries

Offline tests cover parser/schema reuse, timeouts, hysteresis, inactive stale
symbols, subscription changes, batching, cache isolation, actual loopback SSE,
browser renderer channel isolation and worker lifetime. A separate acceptance
script measures full-only baseline versus concurrent fast/full polling, CPU/RSS,
threads and wire SSE timestamps. Public-network latency comparisons are
observational; they cannot establish causality or replace a browser screenshot.
