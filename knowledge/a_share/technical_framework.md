# 技术分析框架

固定顺序：市场状态 → 趋势结构 → 价格位置 → 均线结构 → 量价 → 换手 → 波动 → 突破/回踩 → 日内行为 → 风险。

趋势需同时检查价格与 MA5/10/20/60、均线方向、高低点结构、20日位置、ATR、量价和突破状态。仅站上 MA5 不足以判多。

行为词典：放量/缩量突破、放量滞涨、缩量回踩、放量下跌、缩量上涨、平台或假突破、冲高回落、探底回升、高开低走、低开高走、长上下影、加速、衰竭、强势横盘、高位震荡、低位放量、缩量整理。每项判断都必须给最低证据；不能从形态直接推出必涨、主升浪或目标价。突破必须检查位置、相对量、收盘位置、后续承接和市场环境。
